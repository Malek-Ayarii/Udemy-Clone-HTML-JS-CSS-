Leçon 1 sur 4

Introduction au CSS

Le CSS (Cascading Style Sheets) décrit l’apparence d’une page : couleurs, polices, espacements, mise en page. On l’écrit dans un fichier séparé, relié au HTML avec la balise <link>.

<link rel="stylesheet" href="css/style.css">

Une règle CSS est composée d’un sélecteur et de déclarations :

h1 {
  color: #a435f0;
  font-size: 2rem;
}

.carte { border-radius: 8px; }  /* une classe */
#menu  { display: flex; }       /* un identifiant */

Leçon 2 sur 4

Le modèle de boîte

  • content : le contenu (texte, image)
  • padding : l’espace intérieur, autour du contenu
  • border : la bordure
  • margin : l’espace extérieur, entre les éléments
*, *::before, *::after {
  box-sizing: border-box; /* la largeur inclut padding et bordure */
}

.carte {
  padding: 16px;
  border: 1px solid #d1d7dc;
  margin-bottom: 24px;
}

Astuce : ajoutez toujours box-sizing: border-box, les tailles deviennent beaucoup plus faciles à calculer.

Leçon 3 sur 4

Flexbox

Flexbox sert à aligner des éléments sur une seule dimension : en ligne ou en colonne. C’est l’outil idéal pour une barre de navigation ou une rangée de boutons.

.menu {
  display: flex;
  justify-content: space-between; /* axe principal */
  align-items: center;            /* axe secondaire */
  gap: 16px;
}

Les propriétés essentielles

  • flex-direction : row ou column
  • flex-wrap: wrap : passe à la ligne si manque de place
  • flex: 1 : l’élément prend l’espace disponible

Leçon 4 sur 4

Grid et responsive

CSS Grid gère la mise en page en deux dimensions : lignes et colonnes. La grille des cours de la page d’accueil utilise cette technique :

.grille {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 24px;
}

Les media queries

Elles appliquent des styles selon la taille de l’écran. On adapte ainsi la page pour mobile, tablette et ordinateur.

/* Tablette */
@media (max-width: 900px) {
  .layout { grid-template-columns: 1fr; }
}

/* Mobile */
@media (max-width: 600px) {
  .menu { flex-direction: column; }
}

À retenir : Flexbox pour aligner sur une ligne, Grid pour construire la structure de la page.
