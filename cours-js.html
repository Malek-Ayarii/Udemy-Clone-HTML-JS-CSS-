Leçon 1 sur 4

Introduction au JavaScript

JavaScript est le langage de programmation du navigateur. Il permet de modifier la page sans la recharger : ouvrir un menu, valider un formulaire, afficher une barre de progression…

On place le script à la fin du <body>, dans un fichier séparé :

<script src="js/main.js"></script>

Astuce : ouvrez la console du navigateur avec F12 et tapez console.log("Bonjour") pour tester.

Leçon 2 sur 4

Variables et fonctions

Une variable stocke une valeur. On utilise const si elle ne change pas, et let si elle peut changer.

const prenom = "Sara";   // texte (string)
let score = 0;           // nombre (number)
let estConnecte = true;  // booléen (boolean)
const cours = ["HTML", "CSS", "JS"]; // tableau

score = score + 10;
console.log(prenom + " a " + score + " points");

Les fonctions

Une fonction regroupe des instructions réutilisables. Elle peut recevoir des paramètres et renvoyer un résultat.

function calculerProgression(terminees, total) {
  return Math.round((terminees / total) * 100);
}

console.log(calculerProgression(2, 4)); // 50

Leçon 3 sur 4

Le DOM

Le DOM (Document Object Model) représente la page sous forme d’arbre. JavaScript peut sélectionner un élément de cet arbre puis le modifier.

// Sélectionner
const titre = document.querySelector("h1");
const cartes = document.querySelectorAll(".card");

// Modifier
titre.textContent = "Nouveau titre";
titre.classList.add("actif");
titre.style.color = "#a435f0";

Leçon 4 sur 4

Les événements

Un événement est une action de l’utilisateur : un clic, une saisie, un défilement… On l’écoute avec addEventListener.

const bouton = document.querySelector("#demo-btn");
let clics = 0;

bouton.addEventListener("click", function () {
  clics++;
  document.querySelector("#demo-count").textContent = clics;
});
