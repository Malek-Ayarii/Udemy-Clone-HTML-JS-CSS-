Leçon 1 sur 4

Introduction au HTML

Le HTML (HyperText Markup Language) est le langage qui décrit le contenu d’une page web : titres, paragraphes, images, liens… Il ne s’occupe pas de l’apparence (c’est le rôle du CSS) ni des interactions (c’est le rôle du JavaScript).

Le HTML fonctionne avec des balises. La plupart vont par paire : une balise ouvrante et une balise fermante qui entourent le contenu.

<p>Ceci est un paragraphe.</p>

À retenir : HTML = le contenu, CSS = le style, JavaScript = le comportement.

Leçon 2 sur 4

Structure d’une page

Toute page HTML5 commence par la même base. Le <head> contient les informations pour le navigateur, et le <body> contient ce qui est affiché.

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Ma page</title>
</head>
<body>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</body>
</html>

Les balises sémantiques

  • <header> : l’en-tête (logo, menu)
  • <nav> : la navigation
  • <main> : le contenu principal, unique dans la page
  • <footer> : le pied de page

Leçon 3 sur 4

Textes, liens et images

Les titres vont de <h1> (le plus important) à <h6>. Utilisez un seul <h1> par page, puis des sous-titres dans l’ordre.

<h1>Mon blog</h1>
<h2>Mon premier article</h2>
<p>Un texte avec un mot <strong>important</strong>.</p>

Les liens

La balise <a> crée un lien. L’attribut href indique la destination.

<a href="contact.html">Me contacter</a>

Les images

La balise <img> n’a pas de balise fermante. L’attribut alt est obligatoire : il décrit l’image pour les personnes malvoyantes et pour le référencement.

<img src="chat.jpg" alt="Un chat roux endormi">

Astuce : vérifiez votre code avec le validateur du W3C (validator.w3.org) pour repérer les erreurs.

Leçon 4 sur 4

Les formulaires

Les formulaires permettent à l’utilisateur d’envoyer des informations : connexion, inscription, recherche… Chaque champ doit avoir un <label> relié par l’attribut for.

<form action="/inscription" method="post">
  <label for="email">E-mail</label>
  <input type="email" id="email" name="email" required>

  <label for="mdp">Mot de passe</label>
  <input type="password" id="mdp" name="mdp" minlength="8">

  <button type="submit">S’inscrire</button>
</form>

Les types de champs utiles

  • email, tel, url : clavier adapté sur mobile
  • number, date, range : saisies spéciales
  • required : rend le champ obligatoire, sans JavaScript
